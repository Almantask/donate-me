# Security & impersonation

## The only official donation page

**https://almantask.github.io/donate-me/**

- Checkout always happens on a `stripe.com` address and shows **Almantask** as the recipient.
- I will **never** ask for donations by DM, email, social media, gift cards, crypto or bank transfer.
- A copy of this page hosted anywhere else is not mine. Please don't pay through it.
- The thank-you page does not prove that anyone donated. Only Stripe receipts do.

### Lietuviškai

- Vienintelis oficialus paramos puslapis: **https://almantask.github.io/donate-me/**
- Mokėjimas visada vyksta **stripe.com** adresu, o gavėjas nurodytas kaip **Almantask**.
- **Niekada** neprašysiu paramos žinutėmis, el. paštu, socialiniuose tinkluose, dovanų kortelėmis, kriptovaliuta ar banko pavedimu.
- Šio puslapio kopija bet kur kitur nėra mano. Per ją nemokėk.

## Found a fake page or someone impersonating me?

1. Don't pay, and don't share your card details.
2. Report the copy:
   - If it's hosted on GitHub: https://github.com/contact/report-abuse (choose "impersonation")
   - If it uses a Stripe checkout with a different recipient: https://support.stripe.com/contact
3. Let me know by opening an issue in this repository.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (**Security → Report a vulnerability** in this repository) instead of a public issue.
